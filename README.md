# NUS-ISS DDAS

## Requirements
- JDK 17
- Maven 3.9.x
## Setup
1. Ensure JDK 17 is installed and set as JAVA_HOME in your environment variables
2. Ensure maven is installed. Verify by running 'mvn -version' and checking your maven and Java version.
3. In cmd, go to nusiss-ddas-springboot (eg. 'cd nusiss-ddas-springboot') and type in 'mvn spring-boot:run'. This will download all the dependencies required.
4. Once the cmd says 'Started DdasDemo in XX.XXX seconds', go to your browser and go to 'http://localhost:8080/'
5. Register an account and login (to a currently empty page)
